# Windows 11 CCTV Workstation Security Baseline

**Security design and documentation**

> Repository status: project overview published. Original source files, configurations and supporting documentation will be added later. No runnable implementation is included yet.

## Overview

Designed and documented a security baseline for a dedicated unmanaged Windows 11 Pro CCTV workstation. The design covers encryption, least privilege, application allowlisting, kiosk/USB restrictions, host firewall and audit logging, with mappings to recognised security frameworks. The repository describes the baseline design; deployment of every control and formal approval are not independently established here.

## Technologies

Windows 11 Pro · Encryption · Least privilege · Application control
